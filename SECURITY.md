# Security policy

This package includes sign-in, session and email helpers used by live Wiltshire Scouts sites, so we take security reports seriously.

## Reporting a problem

Please do not open a public issue, pull request or discussion about a security problem.

Report it privately through GitHub instead: go to the [Security tab](https://github.com/wiltshirescouts/website-templates/security) and choose **Report a vulnerability**.

Include:

- what the problem is and which part of the package it affects (for example `src/server`)
- the version or commit you tested
- steps to reproduce it, or a proof of concept
- what an attacker could do with it

## What happens next

We aim to reply within 5 working days. This is run by volunteers, so it may sometimes take longer. We will tell you whether we can reproduce the problem, keep you updated while we fix it, and credit you in the release notes unless you would rather not be named.

## Supported versions

Only the latest release gets security fixes. Sites should keep up to date through the Dependabot pull requests.
